# Illustrations

55 SVG files exported from the running app on 6 November 2026. In the app every picture is drawn by JavaScript at run time; these files are faithful snapshots of that output, with colours resolved for the default Grape theme in day mode, for reuse in documents, decks and print.

- `finn-accessory-*.svg`: Finn the fish wearing each accessory (no hat, party hat, cool shades, flower crown, big bow, captain hat, headphones).
- `finn-mood-*.svg`, `finn-today-buddy.svg`: Finn's moods (overjoyed, sleepy, the Today screen).
- `journey-map.svg`, `journey-mini-trail.svg`: the full nine-place journey map and the small trail on Today (with sample progress).
- `place-sticker-*.svg`: the nine place stickers (Base Camp to Cloud Castle).
- `party-effect-*.svg`: the ten party-effect icons.
- `story-*-slide-*.svg`: the pictures from every Learn story.
- `unhookd-logo.svg`: the app logo.
